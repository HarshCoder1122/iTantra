# Security Policy

## Supported versions

Only the latest commit on the `main` branch of iTantra receives fixes.

## Reporting a vulnerability

Please **do not** report security issues in public issues or pull requests.

Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/HarshCoder1122/iTantra/security/advisories/new).

Include a description, reproduction steps, and the potential impact. You can expect an acknowledgement within a few days, and we will keep you updated until the issue is resolved.

## Handling secrets

This project must never contain real credentials. If you spot an API key, token, or password in the repository or its history, report it privately as above so it can be rotated.
